## One paragraph

I built and operate **Halo**, a TypeScript/React/Next.js Ask product that invited users actually use. I version the code in Git and ship production patches to Vercel after people start depending on it. In the same repo, **VocalLearn** is a React Native voice tutor I run on a real iPhone (Supabase/Postgres, Grok, spaced repetition). Together that is application development with OOP-style TypeScript, databases, APIs, and production deploys — not a tutorial dump.

- Do not treat family/early-access usage as a large consumer user count.
