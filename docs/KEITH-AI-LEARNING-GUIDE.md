## Verdict

Same diagnosis, different product. Keith is teaching undergraduates how to stop ChatGPT from thinking for them. Halo is the family protocol that still runs when nobody reads 62 pages: answer first, harvest only what is worth keeping, force a retrieve, space it, graduate it.

Unstructured AI can make people *worse* (Dell’Acqua et al. 2023: structured use ~+40% work quality; unstructured ~−19% vs no AI). Microsoft 2025 (Lee et al.): people most confident they are “good at AI” often showed the largest drop in critical thinking. Halo’s one-liner is the product form of that finding — not a ChatGPT clone.

## What differs (do not copy)

Keith is writing for a student with a syllabus, a midterm, and a professor’s AI policy. His default course instructions say: before answering, ask what they already know; if they want the answer, push back. Correct for BIO 301. Wrong for “capital of Utah” from a parent on the couch.

| Keith (university OS) | Halo lock |
| --- | --- |
| Socratic intercept on every question | **Never** withhold the answer. Reading is free. Encoding is a click. |
| One Claude project per class; upload syllabus + textbook + past exams | User curiosity is the library. No K-12 / shared curriculum corpus. |
| 58-skill Claude Cowork plugin (papers, proofs, quals, cover letters, burnout) | One Keep loop. Competing there is Claude’s job. |
| Timed 15–20 question exams, score dashboards, concept-map theater in chat | Sunday freeze: no score, no timer, no percent. Visual study tools stay with Teach-me / exhibits, not 1.3. |
| Academic-integrity disclosure writer | Family product. Not a coursework coach. |
| Consensus / Scholar Gateway + “ask Gemini as a second opinion” | Search + citations on live/depth already. No citation database. No second-model workflow. |

## Later, if Teach-me ships (not 1.3)

Thin Teach-me on the **existing play sheet**, depth asks only:

- Start from **their take** (“what do you think this is?”), then lock the atom — not a lecture.
- Climb Bloom-style: define → apply → compare → combine. Not another SEE clone.
- Closed chips stay token SAY. Open gist / blank-page “explain it from scratch” is for meaning, when open play is allowed.
- Productive friction belongs here. Do not put a mode-diagnostic score on Home.

Fluent Luna that harvests the **wrong atom** (or none) is Keith’s illusion-of-knowing in product form. Primary-chip-first and cue uniqueness stay the fix — not a longer answer.
