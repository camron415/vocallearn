## Quick capture (Mac)

1. Open https://halo-gules-three.vercel.app/preview in Chrome (desktop width ~1200px).
2. Mix → **Loop** → **Demo pack** → **Due now** as needed.
3. `Cmd+Shift+4` → drag region → save into this folder with the names above.
4. `git add docs/screenshots/*.png && git commit -m "Add README screenshots"`
