## Bead inspect spec — **panel, not sheet**

### Decision

**One-fact header panel**, same family as `GoldKeptBadge` (`gold-kept-panel`): paper card, composer-width cap, Esc / outside dismiss. **Not** `MenuSheet`. **Not** the play sheet. **Not** a Library page. **Not** `#cove-overlay` tour.

Why panel:

- Sunday already locked gold as “plain panel anchored under the icon — not a page, not an overlay over the field.”
- `LIBRARY-BACKLOG.md` parked the same pattern: tap bead → read-only prompt/answer/rank, gold-panel voice.
- A sheet growing from the composer (`MenuSheet`) is the wrong object. Play sheet 832px is the round. Covering Home/Chat to read one fact is noise.

Why not sheet: History/Settings already own the sheet motion. Inspect is a glance, not a destination. A sheet would also sit at z ~100 and fight harvest flies (120).

### Trigger

| Object | Today | v1 inspect |
| --- | --- | --- |
| In-progress Keep bead | `<span title>` | `<button>` (or role=button). Tap opens **one-fact Keep panel**. |
| Gold ◎ | Button → list panel | **Unchanged.** That list *is* gold inspect. Rows stay non-tappable (Sunday + `pointer-events: none`). |
| Home due chip | Opens play round | Unchanged. Do not add inspect on due chips. |
| Harvest span in chat | Origin for flyers | Unchanged. Do not make marks tappable (would steal `data-harvest` origin). |

Mutually exclusive: Keep inspect and ◎ panel never both open.

### Panel chrome

```
┌─ Keep ─────────────────────────────────┐
│ What is usually named as the longest…  │  ← chip.prompt (primary)
│ The Nile · Where                       │  ← answer · KIND_LABEL
│ New                                    │  ← rank word only
└────────────────────────────────────────┘
```

- **Title:** `Keep` (in progress). Gold panel stays `Kept`. Do not merge the two titles.
- **Type:** reuse `.gold-kept-prompt` / `.gold-kept-meta` / summary size (`0.82rem` / 450 / 52% ink). End-card voice, not token|answer columns.
- **Rank words:** `New` / `Bronze` / `Silver` from `keepRank` 0/1/2. Do not draw a second metal rim in the panel. The bead already has the 3px inset.
- **Due line:** omit in v1 unless Lane 3 hands a ready-made `dueLabel` string. Do not invent “in 3 days” math here.
- **Not in v1:** edit, delete, open source chat, flip animation, cluster siblings, overflow `+N`.

### Anchor, z, motion

- Anchor to the **tapped bead** `getBoundingClientRect()` (pocket is on the right). Gold stays left-of-Cove. Do not reuse Cove-left for Keep inspect.
- Width: `min(var(--halo-chat), calc(100vw - 2rem))`. Phone: still a panel, not a bottom sheet.
- `z-index: 40` (same as gold panel). **Never 120.** Harvest flies stay above.
- Motion: opacity 180ms only. No MenuSheet grow. No harvest arc. Soft / `prefers-reduced-motion`: instant show.
- Dismiss: Esc, pointer outside, second tap on the same bead, opening ◎, starting a round.

### Hit target (diameter frozen)

Visible bead stays `var(--keep-slot)` (~1.02rem in LoopSkin). On coarse pointer, expand the **button’s tap box** (padding / `::after` slop) toward ~44px without changing painted diameter or `--keep-slot`. Lane 6 verifies iPhone; we do not enlarge the dot.

### Data we already have (no keep-memory edit)

`KeepPocket` already maps live `HarvestChip`s: `id`, `prompt`, `answer`, `kind`, `keepRank`, `keptAt`. Inspect is chrome on that array. If Lane 3 later adds overflow count or `dueLabel`, we can show it; **do not block inspect on a new API.**

### Gold panel tweaks this wave

None required for inspect. Optional later: empty ◎ click still opens the panel with `None mastered yet` so the control does not feel dead — only if Camron asks. Not a top ticket.
